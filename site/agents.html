Make it yours

Customize thermo with an AI coding agent

thermo does what one household needed, on an Android phone. Yours may need it on a laptop, readings in Home Assistant over MQTT, Fahrenheit, or a different thermometer. You don't have to wait for someone to add it. A coding agent can do most of the work, and the repository is set up to help it. The Android app itself was made this way, ported from a terminal version overnight.

Why this code base is agent-friendly

  • AGENTS.md at the root explains the layout, the build and test commands, the firmware protocol and the rules (never write to your devices unasked). Claude Code reads it through CLAUDE.md, and most other agents read AGENTS.md directly.
  • The hard parts are pure. The BTHome decoder, the byte layouts of the firmware commands and the calibration maths don't touch Android, and the app's whole state lives in one I/O-free model. All of it is covered by unit tests that run on a computer, without a phone or thermometers.
  • The platform-specific parts are small and named: the Bluetooth scanner and job worker, the GATT client, and the Compose screens.
  • Tests on real data. Some tests replay real calibration sessions from history files, so a change to the fit is checked against what actually happened.
  • A demo for the screens. Debug builds load simulated thermometers with hours of history, so an agent can drive the app on a phone over adb without touching yours.

How to do it

  1. Get the code and an agent.

    Clone the repository and start your agent in it, for example Claude Code:

    git clone https://github.com/arturzielazny/atc-thermo
cd atc-thermo
claude
  2. Ask for a plan first.

    For anything bigger than a tweak, ask the agent to read AGENTS.md and propose a plan before editing. In Claude Code, plan mode (Shift+Tab) does exactly that.

  3. Let it build and test in a loop.

    Tell it the finish line: "./gradlew testDebugUnitTest and lintDebug pass". Agents work best when they can check themselves. With a phone connected over USB, it can also install the app and look at the screens.

  4. You test with hardware.

    The agent can't see your thermometers. Check the readings, then try one write action (rename is the safest) on one device before calibrating all of them.

Prompts to start from

Copy one, then add your details: phone, how many devices, what you want to see.

thermo on a computer again

Read AGENTS.md and archive/tui/AGENTS.md. The terminal version of thermo in archive/tui (Rust, Linux and macOS) was archived when only the Android app was kept up. Bring it up to the Android app's features, with the Android code as the reference: first list what the app does that the terminal version doesn't (the guided calibration session with its precision estimate and times, the hold after a move, the salt box, and so on), then port them one at a time, with the app's tests ported too. Keep the CSV files compatible. Plan first, and keep cargo test and clippy green after each step.

Readings to Home Assistant over MQTT

Read AGENTS.md. Add an optional MQTT publisher to the app: a setting with the broker address, and each reading published as JSON (topic thermo/<name>) with Home Assistant MQTT discovery, also while recording in the background. Keep the model I/O-free and don't block on network errors.

Fahrenheit

Read AGENTS.md. Add a °F display option to the app's menu. Keep storage and calibration in °C, convert only for display (cards, chart axis, calibration screens, widget, notifications and spoken progress), and remember the choice.

Another pvvx device

Read AGENTS.md. I have <model> thermometers on pvvx firmware <version>. Compare its config layout and LCD limits in the pvvx sources with atc/Encodings.kt, and make identify, settings and calibration work for it. Don't connect to any device; I'll test.

Your language

Read AGENTS.md. Move the app's texts into Android string resources and add a <language> translation, spoken progress included. Keep the wording plain, as in the English texts.

Keep your devices safe. Agents should never run write actions against your thermometers unasked, and AGENTS.md tells them so. Calibration is reversible (Restore factory calibration brings back the factory coefficients), and a mistaken setting can be fixed again from the app or the pvvx web flasher, but it's still your call.
